# Zemes atpirkšanas iesnieguma pieņemšanas kārtība

Ministru kabineta noteikumi Nr.1173
Rīgā 2013.gada 22.oktobrī (prot. Nr.55 54.§)

Izdoti saskaņā ar likuma "Par kompensāciju par saimnieciskās darbības
ierobežojumiem aizsargājamās teritorijās" 9.panta piekto daļu

1. Noteikumi nosaka zemes atpirkšanas iesnieguma (turpmāk – iesniegums) pieņemšanas kārtību.

2. Iesniegumu zemes īpašnieks vai mantinieks (turpmāk – iesniedzējs) iesniedz Dabas aizsardzības pārvaldē vai, ja īpaši aizsargājamo dabas teritoriju izveidojusi pašvaldība, pašvaldības domē vai pašvaldības noteiktā institūcijā (turpmāk – atbildīgā institūcija). Iesniegumu var iesniegt klātienē, pa pastu vai elektroniski atbilstoši normatīvajiem aktiem par elektronisko dokumentu noformēšanu.

3. Iesniegumu sagatavo saskaņā ar šo noteikumu pielikumā norādīto paraugu.

4. Ja iesnieguma pamatotai izskatīšanai nepieciešama papildu informācija, atbildīgā institūcija nosaka iesniedzējam saprātīgu termiņu tās iesniegšanai. Ja atbildīgā institūcija noteiktajā termiņā nesaņem norādīto informāciju, atbildīgā institūcija iesniegumu atzīst par neiesniegtu un pēc iesniedzēja pieprasījuma atdod to atpakaļ iesniedzējam.

5. Ja pēc iesnieguma iesniegšanas iesniegumā ietvertajā informācijā rodas tādas būtiskas izmaiņas, kas var ietekmēt kompensācijas − zemes atpirkšana − piešķiršanu, iesniedzējam ir pienākums par tām nekavējoties rakstiski informēt atbildīgo institūciju.

Ministru prezidents Valdis Dombrovskis

Zemes atpirkšanas iesniegums

Saskaņā ar likumu "Par kompensāciju par saimnieciskās darbības ierobežojumiem aizsargājamās teritorijās" lūdzu piešķirt kompensāciju – zemes atpirkšanu − par zemi, kas atrodas dabas rezervātā vai citas īpaši aizsargājamās dabas teritorijas dabas rezervāta, stingrā režīma vai regulējamā režīma zonā.

|  |
| --- |
| (īpaši aizsargājamā dabas teritorija un funkcionālā zona, kurā atrodas zeme) |
|  |
| (novads, pagasts vai pilsēta) |
|  |
| (zemes īpašuma nosaukums) |
|  |

|  |
| (zemes platība atpirkšanai, hektāri) |

Apliecinu, ka:

1) zeme nav apbūvēta;

2) zemes īpašniekam īpašuma tiesības uz zemi nostiprinātas zemesgrāmatā;

3) zemes robežas starp vairāku zemes īpašnieku vai tiesisko valdītāju īpašumiem ierīkotas atbilstoši normatīvajos aktos par zemes kadastrālo uzmērīšanu un Civillikumā noteiktajām prasībām;

4) ja zemes īpašums pieder vairākiem īpašniekiem, – iesniegums iesniegts visu kopīpašnieku vārdā;

5) par zemesgabalu nav saņemta kompensācija – atlīdzība (maksājums no valsts vai pašvaldības budžeta) saskaņā ar likumu "Par zemes īpašnieku tiesībām uz kompensāciju par saimnieciskās darbības ierobežojumiem īpaši aizsargājamās dabas teritorijās un mikroliegumos" (šis punkts nav attiecināms, ja pēc šajā punktā minētās atlīdzības saņemšanas ir uzlikti papildu mežsaimnieciskās darbības ierobežojumi);

6) par zemesgabalu šajā gadā nav piešķirta kompensācija no Eiropas Savienības fondu līdzekļiem;

7) meža zemes platībai atbilstoši normatīvajiem aktiem par meža inventarizācijas kārtību ir spēkā esoša meža inventarizācijas lieta;

8) par iepriekšējo gadu un kārtējo gada ceturksni ir samaksāts nekustamā īpašuma nodoklis;

9) ja zemes īpašniekam uzlikts naudas sods par pārkāpumiem vides jomā, kā arī ja zemes īpašnieka vainas dēļ videi vai mežam nodarīti zaudējumi, – normatīvajos aktos par pārkāpumiem vides jomā noteiktajā kārtībā naudas sods ir samaksāts un videi un mežam nodarītie zaudējumi ir atlīdzināti.
